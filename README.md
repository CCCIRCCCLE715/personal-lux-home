# 黄白个人首页

浅灰白＋明黄个人首页：真人头部贴纸、滚动卷纸、七件立体物体、半露斜插的视频封面、点赞/收藏/转发互动图标。

## 隔离与运行

所有修改与素材位于本目录，不修改同级手表项目。`pnpm dev` 固定 http://localhost:5178，`pnpm preview` 固定4178，均使用strictPort。`pnpm build` 输出dist。

如果接管环境执行 `pnpm dev` 提示 `node: not found`，运行 `./start-local.sh`。该脚本会自动寻找系统 Node.js 或本机 Codex 自带的 Node.js。Kimi 的完整接管说明见 `KIMI_HANDOFF.md`。

## 动效与空间

头像桌面尺寸约为原始版本2.05倍。初始完整，细分纸张卷起后向左上角离场，白色纤维边随右侧向左侧的撕裂前沿逐段揭露，不做透明度淡入。下半片使用从旧纸张参考提取的连续纤维外轮廓，上半片沿更内侧的彩色图像边贴合并遮住纤维；仅在揭开后叠加中性白色纸纤维，不使用蓝色背景作为孔洞遮罩。没有黑色椭圆开口或背景大块投影；近距离轮廓阴影与模型间投影表现空间关系。

标题现在使用项目内置Teko 600（用户在五款候选中选定第4款，见`public/font-preview.html`）；桌面单行两端分布，字号clamp(170px,16.5vw,320px)，平板（651-1000px）与手机（≤650px）错开两行、词宽更窄（平板19vw、手机21vw），整体位于头像、模型后方，桌面上移100px、手机75px。侧栏文案、漂浮词与顶栏标语已移除，头像贴纸放大（桌面2.05倍）。粉色大脑下移，约一半位于纸边后方。模型竖插并按深度分开；60秒、361个动画时刻的保守包围盒检测无相交，所有模型位于纸片后方。浏览器`.paper-webgl`的data-model-sources与data-model-clearance记录实际加载和检测结果。
